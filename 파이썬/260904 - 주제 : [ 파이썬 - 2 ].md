\* \[ **리스트와 튜플 그리고 딕셔너리 ( 중요 )** ] :

\*\*\[ ]\*\*형태로 감싸진 변수는 **리스트**, . **튜플**은 \*\*()\*\*로 감싸졌으며 **name, pin = pins** 형식으로 **언패킹**해도 문제가 없다

하지만 \*\*{}\*\*로 감싸진 **딕셔너리**인 경우 name, pin = pins.items()의 형태로 언패킹해야 key 두개가 나올 수 있다. 단 이것은 하나만을 꺼내는 것으로 딕셔너리 내부에 여러 값이 존재하는 경우 **for** name, pin **in** pins.items() : 형태로 **순회**시켜야 여러 값을 출력할 수 있다.



\* \[ **a.append(n)** ] : 배열 or 함수(컨테이너) a에 n을 추가해라



\* \[ **c = a.copy()** ] : 겉 리스트를 새로 만들어 a를 c에 복사한다. 하지만 \[\[10,20],30] 같은 꼴에선 안쪽 리스트는 공유된다



\* \[ **c = copy.deepcopy(a)** ] : a를 c에 복사한다. **c의 값은 독립**되어 a의 내부값에도 영향을 주지 않는다.



\* \[ **sorted(a) 과 a.sort()** ] : **sorted(a)는  a를 오름차순으로 정렬하여 출력**한다. **정렬된 값**은 **원본에 영향을 주지 않는다**.

&#x09;					      **a.sort**는 **원본 a를 오름차순으로정렬**한다. **원본 a**는 **변화되어** 이후 **정렬된 값**을 **출력**한다.

&#x09;					     sorted(a, **reverse=True**) 형태로 **내림차순**으로 정렬이 가능하다.

name, pin = a 입력 시 hi는 name에 3은 pin에 저장되어 출력도 동일하게 되며 이를 **언패킹**이라고 한다.

**mn, \*rest** = sorted(\[3, 1, 2]) 입력 시 **mn은 정렬된 1**이, **\*가 붙여진 rest**는 **나머지 값들**이 **저장**되어

\* \[ 키 재대입과 없는 키 ] : 캍은 키 재대입 = 덮어쓰기. 키는 중복될 수 없다.

```

print(pins.get("SERVO"))  			- pins 내부에 존재하지 않기에 **None**이라고 출력된다.

print(pins.get("SERVO", -1))    # 기본값	- 존재하지 않기에 **None**이나 이미 쓰인 **기본값 -1만이 그대로 출력**된다.
```
