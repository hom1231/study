class SensorReading:

    def \_\_init\_\_(self, node\_id, t, h=0, d=0):

        self.node\_id = node\_id; self.t = t; self.h = h; self.d = d

    def \_\_repr\_\_(self):

        return f"Reading({self.node\_id}, T={self.t})"

    def is\_alert(self):

        return self.t > 35

    def to\_dict(self):

       return {"id": self.node\_id, "T": self.t, "H": self.h, "D": self.d}

   @classmethod

   def from\_dict(cls, d):

       return cls(d\["id"], d\["T"], d\["H"], d\["D"])   # cls = 설계도



r  = SensorReading("ESP32-01", 25.3, 60, 120)

**r1.ALERT\_T = 30 대입의 효과는?**

1\. 클래스 변수가 30이 된다

2\. r1에만 인스턴스 변수가 새로 생겨 클래스 값을 가린다

3\. 모든 인스턴스가 30

4\. 오류

**인스턴스에 대입하면 인스턴스 변수가 생깁니다. 전체를 바꾸려면 SensorReading.ALERT\_T = 30.**

1\. 속도 향상
