■ 1. 오늘 배운 주요 단어 / 문법

\--------------------------------------------------

(형식: \[단어/명령어] : 의미 - 부연설명)



\* \[ 반가산기 ] : XOR, AND 두 개 사용
```
	     XOR = SUM 둘이 다른가 확인 - 이 자리에 쓸 것

                    AND = Carry 둘 다 1인가 확인 - 윗자리로 올릴 것 ( 1+1 행 확인을 위해 존재 )

```

\* \[ 전가산기 ] : 반가산기 두 개 , OR 한 개 사용
```
	     XOR = SUM 1이 홀수 개인가 - XOR 두번 사용

                   Cout = 1이 2개 이상인가

	     검산: A + B + Cin = (2\*count) + sum
```
	    반가산기 8개 이으면 8비트 덧셈기 -


\* \[ n<<1 ] : 왼쪽으로 한칸 옮기면 그 값이 양수는 두배, 음수도 두배가 된다



\* \[ n>>1 ] : 오른쪽으로 한칸 옮기면 그 값이



**모든 비트 연산은 정수에서만 사용이 가능하다.**

**실수의 비교는 같다 표시인 "=" 를 쓰지 말 것.**

■ 2. 핵심 코드 \& 로직 흐름

\--------------------------------------------------

\[구현 목표 1 : 2진수의 연산 ]

↓↓↓ Code ↓↓↓
```
REG |= (1 << n); - OR 연산으로 켜기 담당임.



REG \&= \~(1 << n); - AND + NOT 연산으로 끄기 담당



REG ^= (1 << n); - XOR 연산으로 토글( 킨 것은 끄고 끈 것은 킨다. )



REG \& (1 << n) - AND 연산으로 검사 담당


char a=3, b=4; 			|

&#x09;				|

a ^= b;				| - a값은 b로 b값은 a로 바꾸는 XOR을 활용한 코딩

b ^= a;				|

a ^= b;				|



if(a!=b) - ( a와 b가 다를 경우 조건을 건다. )

a ^= b ^= a ^= b ( 위 공식을 축약시킨 식 )
```

2.`REG \\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\&= (1 << 3);` 을 실행하면 실제로 벌어지는 일은?



비트 3만 꺼지고 나머지는 그대로 남는다

아무 변화도 없다

비트 3만 남고 나머지가 전부 꺼진다

모든 비트가 켜진다





\* \[ 답: 3번] : AND 마스크는 마스크가 1인 자리만 남긴다. 비트 3만 남고 나머지는 전부 꺼진다.



3\. `REG = 16;` 으로 냉각팬(비트 4)을 켜면 안 되는 이유는?



16이라는 숫자는 8비트에 담기지 않는 값이라서

대입은 CPU가 할 수 없는 동작이라서

냉각팬은 코드로 켤 수 없는 장치라서

다른 장치들이 전부 꺼져서





\* \[ 답: 4번] : 대입은 레지스터 여덟 비트 전체를 덮어써서, 켜져 있던 다른 장치들이 전부 꺼진다
